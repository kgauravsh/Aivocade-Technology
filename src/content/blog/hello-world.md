The file name becomes the URL: `/blog/hello-world/`.

## Writing a new post

1. Create a `.md` file in `src/content/blog/`.
2. Add the frontmatter block at the top (title, description, pubDate).
3. Write the post in markdown below it.

Add `draft: true` to the frontmatter to keep a post off the live site while you work on it.
